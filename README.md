# yulidm

인스타그램 DM 스타일의 대화 이미지 편집기입니다. 서버나 계정 없이 브라우저에서 대화, 링크, 사진을 편집하고 PNG로 저장합니다.

## 실행

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

프로젝트 루트에서 실행합니다. 앱 실행에는 Node.js나 패키지 설치가 필요하지 않습니다. 라이브러리, Inter 폰트, Font Awesome 아이콘은 `vendor/`에 포함되어 있어 외부 CDN에 연결하지 않습니다.

사진 버튼에서 왼쪽/오른쪽을 선택하고 이미지를 업로드한 뒤 자를 영역을 선택해 적용합니다. 사진은 자유 비율, 프로필은 정사각형, 링크 이미지는 기존 비율을 사용합니다. 사진을 클릭하면 다시 선택할 수 있고 취소하면 기존 사진이 유지됩니다. 사진은 선택 영역의 비율을 유지하며 최대 2400픽셀 변으로 저장합니다.

다운로드 버튼에서 **전체 다운로드** 또는 **선택 다운로드**를 고릅니다. 전체 다운로드는 헤더부터 마지막 메시지까지 저장합니다. 선택 다운로드는 저장할 대화를 클릭하거나 키보드 Enter/Space로 고른 뒤 **선택 저장**을 누릅니다. 선택한 대화만 원래 순서대로 헤더와 함께 2배 해상도의 PNG 한 장으로 저장하며, 취소 또는 Esc로 선택을 종료할 수 있습니다. 편집 버튼은 이미지에서 제외됩니다. 긴 대화는 구간별로 렌더링하고 PNG를 순차 인코딩하므로 하나의 거대한 브라우저 캔버스를 만들지 않습니다. 기기의 메모리와 PNG 뷰어의 최대 크기는 여전히 적용되며, 저장 실패 시 오류를 표시합니다.

좁은 화면에서는 가로 스크롤로 대화와 오른쪽 다운로드 버튼까지 이동할 수 있습니다. 테마 전환 버튼은 다크 모드에서 태양(라이트로 전환), 라이트 모드에서 달(다크로 전환)을 표시합니다.

## 브라우저 테스트

Node.js와 Python 3이 필요합니다.

```sh
npm ci
npx playwright install chromium
npm test
```

시스템 Chromium을 사용하려면 `CHROMIUM_PATH=/usr/bin/chromium npm test`를 실행합니다. 테스트는 자체 로컬 서버를 시작하고 외부 HTTP 요청을 차단한 상태에서 실제 Chromium으로 파일 선택, 자르기, 편집, 취소, 링크·프로필, 테마, 너비, 삭제·복원 및 PNG 다운로드를 검사합니다. 32,767픽셀을 넘는 PNG를 디코딩하여 전체 크기와 마지막 사진 픽셀을 검증합니다. 결과 이미지는 무시되는 `test-results/`에 저장합니다.

## 포함된 외부 코드

`vendor/manifest.json`에 원본 npm 패키지의 버전, 다운로드 위치, 무결성 값과 포함 파일의 SHA-256을 기록했습니다. 각 패키지의 라이선스를 해당 디렉터리에 보관합니다. Inter 폰트는 SIL Open Font License를 따릅니다. 런타임 스크립트는 html2canvas 1.4.1, Cropper.js 1.5.13, fflate 0.8.2입니다. Font Awesome 6.0.0과 Inter의 기존 스타일을 유지합니다.
